# Only what the three modules actually import. Verified by grepping imports in
# proxy_defense.py, proxy_harvester.py and mcp_proxy_server.py; packaging/PKGBUILD
# declares the same set as `depends`.
#
# This used to list 18 packages. The other 15 (cachetools, orjson, cryptography,
# tenacity, PyYAML, certifi, fake-useragent, python-dateutil, requests, urllib3,
# aiohttp-socks, expiringdict, pyOpenSSL, python-json-logger, PySocks) were never
# imported. Keeping them was not free: on a newer CPython with no wheel for the
# pinned version, pip built orjson and cryptography from source, which needs a
# Rust toolchain, and the Arch install failed inside cargo.
#
# Bounds rather than exact pins, for the same reason: a rolling-release
# interpreter is better served by "newest version that has a wheel" than by a pin
# that may have to be compiled. CI tests 3.10, 3.11, 3.12 and Arch's python.
#
# The escalation ladder is optional and deliberately NOT installed here. Each
# rung is an extra on the Python package (pip install 'owl-agent-proxy[ja3]'):
#   httpx[http2]           http/2
#   curl_cffi              ja3
#   websockets             websocket
#   playwright             browser  (then: playwright install chromium)
#   invisible-playwright   stealth  (Python >= 3.11, then invisible-playwright fetch)
#   redis                  shared cache / rate-limit state
# install-owl.sh --full installs the first four; http/1.1 needs none of them.
